# Jiuzihun (Nine Souls)

**Online Multiplayer Strategy Card Game**  
_Independent Full-Stack Project_

This project is an independent work sample demonstrating **system design**, **UI/UX**, and **real-time logic** across **desktop and mobile platforms** (including Android & iOS).

---

## 🎮 Project Overview

- Designed and developed a **full-featured browser-based strategy card game** from scratch using **JavaScript**, covering:
  - Core gameplay systems
  - UI / UX design
  - Animations
  - Sound effects & voice lines
  - Background music
  - Visual assets

- Architected a **real-time online multiplayer system** with:
  - Backend server and database deployed on **Render**
  - Player matchmaking
  - Game state synchronization
  - Persistent data management

- Designed a **custom AI decision-making engine** that allows any character to seamlessly switch into **AI-controlled mode** during gameplay.

- Developed a **hybrid AI decision model**, combining:
  - Rule-based constraints
  - Multi-factor game state evaluation  
    to simulate **human-like strategic decision making under uncertainty**.

- Implemented an **AI action-selection system** that evaluates comprehensive in-game state representations, including:
  - Character skill states
  - Card metadata
  - Ally and enemy statuses
  - Timing windows for skill activation
  - Hand composition
  - Probabilistic inference of opponent hands

- Built a **unified data-driven combat and skill system**, where:
  - Cards, skills, characters, and AI behaviors are modeled as structured data
  - All elements are jointly evaluated to compute optimal actions

- Ensured **cross-platform compatibility** across:
  - Desktop browsers
  - iOS & Android browsers  
    with responsive layout adaptation, touch input support, and dynamic screen rotation handling.
